ChatGPT Bridge 0.8.2 fixes long multiline prompts in the current ChatGPT composer.

ChatGPT represents multiline text as contenteditable paragraphs. Reading a detached copy can collapse those breaks even though the live prompt is correct. The bridge now reads ordinary prompt text from the live paragraph structure and still uses a copy when it needs to remove inline tool pills before comparison.

All existing checks for the exact prompt, files, tools, mode, tab, conversation, and visible turns remain in place. A failed pre-Send check still creates no operation record and never activates Send.

## Update

For the simplest upgrade, give Codex this instruction:

> Reinstall the ChatGPT Bridge plugin from tag v0.8.2 at https://github.com/anotb/chatgpt-bridge, then verify `$chatgpt-bridge` in a new task.

For a manual clean reinstall:

```text
codex plugin remove chatgpt-bridge@chatgpt-bridge
codex plugin marketplace remove chatgpt-bridge
codex plugin marketplace add anotb/chatgpt-bridge --ref v0.8.2
codex plugin add chatgpt-bridge@chatgpt-bridge
```

Start a new Codex task afterward.
