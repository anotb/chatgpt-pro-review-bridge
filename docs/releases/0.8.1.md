ChatGPT Bridge 0.8.1 fixes mode selection against the current ChatGPT composer.

ChatGPT now shows both the attachment button and the Power control as menu buttons. The bridge distinguishes the actual Power control by its slider trigger and checks its visible label against the modes ChatGPT currently exposes. Genuine ambiguity still stops before a prompt is composed or sent.

## Update

For the simplest upgrade, give Codex this instruction:

> Reinstall the ChatGPT Bridge plugin from tag v0.8.1 at https://github.com/anotb/chatgpt-bridge, then verify `$chatgpt-bridge` in a new task.

For a manual clean reinstall:

```text
codex plugin remove chatgpt-bridge@chatgpt-bridge
codex plugin marketplace remove chatgpt-bridge
codex plugin marketplace add anotb/chatgpt-bridge --ref v0.8.1
codex plugin add chatgpt-bridge@chatgpt-bridge
```

Start a new Codex task afterward so it loads the updated skill and runtime.
