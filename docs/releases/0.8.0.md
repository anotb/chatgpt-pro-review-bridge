ChatGPT Bridge 0.8.0 is a ground-up simplification of the project. It keeps the useful part—handing work to a visible ChatGPT session and bringing the result back—and removes the framework that had grown around it.

## What changes for users

- One `$chatgpt-bridge` skill replaces the separate Ask Pro and code-review skills.
- Pro, Instant, and other modes are selected from what ChatGPT currently shows.
- Any prompt can include zero, one, or several explicit files.
- File upload stays in the background and does not open the system file picker.
- Long Pro responses can continue for more than an hour and recover after a Codex or computer restart without another Send.
- Complete text, generated files, and generated images come back to the originating Codex task.
- The in-app browser is tried first; Chrome is considered only before submission when the first host is definitely unavailable.

## Breaking changes

The Node API is now centered on `createChatGPTBridge`, `submit`, `collect`, `run`, and `inspectTargets`. The old SDK surface, Python package, backend process, Work and Responses adapters, review-packet builder, locale packs, and compatibility APIs are removed.

Existing saved prompts should replace `$chatgpt-pro-ask` and `$chatgpt-pro-code-review` with `$chatgpt-bridge`.

## Install

```text
codex plugin marketplace add anotb/chatgpt-bridge --ref v0.8.0
codex plugin add chatgpt-bridge@chatgpt-bridge
```

Start a new Codex task after installation. See the [setup guide](https://github.com/anotb/chatgpt-bridge/blob/v0.8.0/docs/setup.md) for sign-in, verification, and 0.7 upgrade instructions.

## Qualification

The release passed 140 focused tests and the full build, bundle, plugin, and package gates. Real visible-session checks covered Instant, High, a Pro response lasting about 41 minutes, same-thread follow-up, restart recovery without resend, two-file input, unexpected staged-file rejection, a generated file, and generated images downloaded with verified hashes.
